### 우리, 같이 있을까요?

1. **모퉁이를 열어요.** 브라우저는 위 **설치 없이 바로 놀기**를 누르면 돼요. Mac은 DMG를 열고 **Chiikawa Corner**를 **Applications**로 끌어 놓아요. Windows는 EXE를 실행하면 내 계정에 설치돼요.
2. **오늘의 나를 골라요.** 닉네임과 캐릭터를 정하고 **우리 방 만들기**를 눌러요. 친구 8종 중 누구든 좋아요.
3. **친구를 초대해요.** **링크 초대**나 **친구 초대**로 복사한 내용을 보내요. 친구는 링크를 열거나 **초대받았어요**에 8자리 코드·초대장을 입력하면 바로 들어와요.

브라우저와 Mac·Windows 앱은 같은 기본 서버에 연결돼요. 같은 8자리 코드로 한 방에서 만날 수 있어요. 방장은 입장을 잠그거나, 초대 코드를 바꾸거나, 친구를 내보낼 수 있어요. 내보내면 초대 코드도 자동으로 바뀌어 이전 코드로는 다시 들어올 수 없어요.

한 방에 최대 **8명**. Mac·Windows 앱에서 **창 접고 바탕화면에서 만나기**를 누르면 작은 친구들만 남아요.<br />
대화창은 캐릭터를 누르거나 Mac **⌘⇧Space** / Windows **Ctrl+Shift+Space**로 다시 열어요. 아직 혼자라면 **먼저 혼자 둘러보기**부터!

브라우저에서는 친구들이 **탭 안의 작은 정원**을 산책해요. 지원 브라우저의 **작은 창으로 띄우기**를 누르면 다른 앱을 보는 동안에도 작은 떠 있는 창에서 채팅할 수 있어요. 원래 탭은 열어둬야 해요. 바탕화면에 캐릭터만 남기는 방식은 Mac·Windows 앱에서 사용할 수 있어요.

브라우저판에서는 여덟 친구가 산책·깡충·손 흔들기·빙글 돌기·빼꼼 등 여러 동작을 해요. 각자 마지막 채팅에서 10분이 지나면 잠든 모습으로 바뀌고, 마지막 채팅이 몇 분 전인지 작게 보여줘요. 새 채팅을 보내면 다시 일어나요. 그림은 여덟 친구의 특징을 참고해 같은 선과 색감으로 새로 그린 비공식 팬아트예요. 앱에도 0.4.0 업데이트로 제공할 예정이에요.

### 새 버전도 가볍게

앱 오른쪽 위 **업데이트 → 업데이트 확인 → 업데이트 다운로드 → 재시작하고 적용** 순서로 눌러요.<br />
다운로드가 끝나도 바로 꺼지지 않아요. 준비됐을 때 재시작하면 돼요.
브라우저는 새로고침하면 새 화면을 받아요.

### 작은 궁금증

<details>
<summary><b>0.1.0을 이미 쓰고 있어요.</b></summary>

0.1.0에는 앱 안의 업데이트 기능이 없어요. **이번 한 번은 위 DMG를 내려받아 Applications의 기존 앱을 교체**해 주세요. 이후에는 앱의 **업데이트** 버튼을 사용하면 돼요.

</details>

<details>
<summary><b>Mac에서 처음 열 때 막혀요.</b></summary>

아직 Apple 개발자 인증·공증을 받지 않은 프로토타입이에요. 이 저장소에서 받은 파일이 맞는지 확인한 뒤, **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**로 앱 하나를 허용할 수 있어요. [Apple 안내](https://support.apple.com/ko-kr/102445)

</details>

<details>
<summary><b>Windows에서 처음 열 때 확인 창이 떠요.</b></summary>

아직 Windows 코드 서명 인증서가 없는 프로토타입이에요. 설치파일의 출처가 이 저장소의 [GitHub Releases](https://github.com/pilgrim13/chiikawa-corner/releases)인지 확인하고 진행해 주세요.

</details>

<details>
<summary><b>내 컴퓨터에서도 되나요?</b></summary>

Mac 앱은 **macOS 13 이상**의 Apple Silicon·Intel 통합 파일이에요. Windows 앱은 **Windows 10·11 x64** 설치파일이에요. Apple Silicon Mac과 GitHub Actions Windows x64에서 실제 설치·실행·업데이트를 확인했어요. 개인 MacBook·Intel Mac 실물 확인은 계속 받을게요.

</details>

<details>
<summary><b>친구 중 일부만 업데이트하면요?</b></summary>

서로 다른 앱 버전에서도 같은 방에서 계속 대화할 수 있어요. 예전 앱은 새 캐릭터 5종의 그림이 없어서 그 친구를 기본 치이카와 모습으로 보여줘요. 새 앱에서는 원래 고른 모습으로 보여요. 업데이트는 각자가 원할 때 앱 오른쪽 위 버튼으로 적용하면 돼요. 지금은 코드만으로 바로 입장해요.

단, 0.2.1 앱은 새 웹 주소가 포함된 전체 초대장을 읽지 못해요. 이전 앱에서는 **같은 서버에 연결한 뒤 8자리 코드만** 입력하거나, 0.3.0으로 업데이트해 주세요.

</details>

<details>
<summary><b>친구 방에 연결되지 않아요.</b></summary>

지금 채팅 서버와 웹판은 개발자의 집 Mac에서 돌아가요. 그 Mac이나 서버 연결이 쉬는 동안에는 친구 방에 접속하지 못할 수 있어요. 설치 앱의 **혼자 둘러보기**는 계속 사용할 수 있어요.

직접 연결 설정을 바꾼 적이 있다면 친구와 같은 서버인지 확인해 주세요. 방이 잠겼거나 이미 8명이 있으면 새로 들어갈 수 없어요.

최근 대화는 100개까지만 보관해요. 지금 만든 방은 서버 업데이트·재시작 후에도 같은 코드와 대화로 돌아올 수 있어요. 모두 나간 방은 정리되고, 모두 연결이 끊긴 방도 10분 뒤 정리돼요.

</details>
